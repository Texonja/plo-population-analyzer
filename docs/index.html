The pipeline does not treat every bet or fold as equivalent. It recreates the strategic state around the action, then emits an observation only when a precisely defined node is reached.

01 / PARSE

Reconstruct the hand

Seats, button, stacks, positions, streets, boards, ordered actions and pot-relative sizes.

02 / MODEL

Identify the node

Missed c-bets, delayed c-bets, probes, barrels, check-raises and the response each creates.

03 / REVIEW

Aggregate with guardrails

Segment by stake and context, expose sample size, compare with versioned review bands and retain an audit trail.

Clear analytical boundaries.

Credible analysis says what the data supports and just as clearly what it does not.

This project is

  • population-level descriptive analytics;
  • a reproducible parser and feature-extraction pipeline;
  • a review workflow with sample-size and privacy guardrails;
  • a local decision-support tool for poker study.

This project is not

  • a multi-account, RTA, bot or collusion detector;
  • a player-profiling system;
  • a solver or causal model;
  • evidence that any account violated a rule.
